# LANTERN Dashboard

A sidebar navigation demo with a hanging lantern that swings to the item you choose and lights the labels around it.

- **HTML · CSS · JS — zero dependencies**
- Pendulum lantern with a warm glow that follows the active nav item
- Label glow falls off with distance from the lantern
- Light + dark themes, keyboard navigation, reduced-motion support

## Use

Open `index.html` in a browser, or use the live page (GitHub Pages).

Click a nav item (or use ↑ / ↓ keys) and the lantern swings to it while the main panel swaps its heading and subtitle.

## Pages

- **Overview** — "Sales are up 12% this week."
- **Orders** — "32 orders to ship today, 4 running late."
- **Clients** — "3 new clients joined this week."
- **Products** — "12 products are low on stock."
- **Reports** — "The weekly report is ready to send."
- **Settings** — "Your workspace is all set."
